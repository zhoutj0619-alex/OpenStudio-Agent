# 爆款脚本模板 — 三种黄金框架

> 这是配合 `agents/writer.yaml` 使用的脚本模板。
> 每种框架对应不同的内容类型和受众心理。

---

## 模板 1：痛点前置型

> 最适合：知识类 / 工具类 / 效率类 / 教程类内容
> 心理机制：观众先感受到痛苦，再获得解药，满足感最强

```
┌─────────────────────────────────────────────────────────┐
│ [0-3秒]   HOOK — 痛点描述                               │
│           "你是不是也每天花 3 小时找选题，最后还找不到？"    │
├─────────────────────────────────────────────────────────┤
│ [3-8秒]   痛苦放大 — 共情 + 后果                         │
│           "我太懂了。选题焦虑是每个创作者的噩梦..."         │
├─────────────────────────────────────────────────────────┤
│ [8-30秒]  解决方案 — 核心价值                            │
│           "直到我搭了这个 AI 选题 Agent..."               │
├─────────────────────────────────────────────────────────┤
│ [30-55秒] 实操演示 — 证据 + 可信度                        │
│           "看好了，我只演示一次..."                       │
├─────────────────────────────────────────────────────────┤
│ [55-60秒] 结果对比 + CTA                                 │
│           "以前 3 小时，现在 30 秒。去 GitHub 自取"        │
└─────────────────────────────────────────────────────────┘
```

### 实际案例

**标题**: 《我受够了找选题，于是写了一个 AI Agent 替我干这事》

**脚本**:

| 时间段 | 内容 | 画面 |
|--------|------|------|
| 0-3s | "你知道一个自媒体人最痛苦的事是什么吗？不是没流量，是每天早上打开空白文档，脑子里也一片空白。" | 创作者抓头发 + 空白文档画面 |
| 3-8s | "我过去每天花 3 小时找选题。刷抖音找灵感，结果刷了 2 小时停不下来。打开小红书找对标，结果被种草了三件衣服。这就是选题困境——你越是想找，越是什么都找不到。" | 手机屏幕录屏，快速切换各平台 |
| 8-30s | "直到我受不了了。我是一个 AI 工作流工程师，我每天都在帮别人搭自动化系统，为什么我自己的选题还要靠手刷？所以我花了 2 个周末，写了一个选题情报官 Agent。" | 代码/终端画面 + 架构图 |
| 30-55s | "看好了，我只演示一次。每天早上 8 点，这个 Agent 自动抓取全网热点，用我的账号定位做匹配，然后生成一份选题日报——含热度评分、切入角度、竞品分析。我喝咖啡的时候扫一眼，选题就有了。" | 屏幕录制：Agent 运行过程 |
| 55-60s | "以前 3 小时，现在 30 秒。这个东西我已经开源了，GitHub 搜 OpenStudio-Agent，Star 一下就能用。评论区告诉我你最头疼的创作环节，下期我专门写一个 Agent 来解决它。" | GitHub 页面 + 二维码 |

## 模板 2：反常识型

> 最适合：观点类 / 认知类 / 行业评论
> 心理机制：打破认知平衡 → 好奇心驱动观看

```
┌─────────────────────────────────────────────────────────┐
│ [0-3秒]   HOOK — 反常识断言                              │
│           "一人公司根本不需要团队，人越多效率越低"          │
├─────────────────────────────────────────────────────────┤
│ [3-10秒]  证据抛出 — 制造悬念                            │
│           "我过去 6 个月的数据说明了一切..."               │
├─────────────────────────────────────────────────────────┤
│ [10-40秒] 层层论证 — 逻辑链                              │
│           "第一...第二...第三..."                         │
├─────────────────────────────────────────────────────────┤
│ [40-55秒] 反转/前提 — 让结论更立体                        │
│           "但有一个前提，99% 的人没做到..."                │
├─────────────────────────────────────────────────────────┤
│ [55-60秒] CTA                                           │
└─────────────────────────────────────────────────────────┘
```

## 模板 3：故事驱动型

> 最适合：个人 IP / Vlog / 复盘类
> 心理机制：人类是天生的故事动物，叙事弧线 = 留存率

```
┌─────────────────────────────────────────────────────────┐
│ [0-5秒]   结果前置 — "我怎么做到的"                        │
│           "我花了 3 个月，把一人公司做到月入 10 万"         │
├─────────────────────────────────────────────────────────┤
│ [5-15秒]  起点 — "我曾经也不行"                           │
│           "但最开始，我连选题都不会找..."                  │
├─────────────────────────────────────────────────────────┤
│ [15-45秒] 转折 & 成长 — "然后我做了这 X 件事"              │
│           "然后我做了三件事：第一...第二...第三..."         │
├─────────────────────────────────────────────────────────┤
│ [45-55秒] 现在的状态 — 收获 + 感悟                        │
│           "现在回头看，最大的收获不是钱，是..."             │
├─────────────────────────────────────────────────────────┤
│ [55-60秒] CTA                                           │
└─────────────────────────────────────────────────────────┘
```

## 脚本自检清单

写完脚本后，逐条核对：

### Hook 检查
- [ ] 前 3 秒有没有钩子？
- [ ] 这个钩子能让我（作为陌生观众）停下来吗？
- [ ] Hook 和后面的内容有关系吗？（避免标题党）

### 内容检查
- [ ] 整个脚本只讲了一个核心信息吗？
- [ ] 有没有「这段能删掉吗」的废话？
- [ ] 观众看完知道该做什么吗？（CTA 是否具体）

### 情绪检查
- [ ] 情绪有起伏吗？（平铺直叙 = 观众划走）
- [ ] 有没有一个「啊哈时刻」（让观众学到新东西的点）？
- [ ] 开头和结尾的情绪差够大吗？

### 口语检查
- [ ] 大声读一遍，像人话吗？
- [ ] 有没有太多书面语/术语？
- [ ] 每句话超过 25 个字了吗？（超过就拆短）

## 使用方式

将 `agents/writer.yaml` 中的 System Prompt 加载到你的 AI 工具中（Claude/ChatGPT/Dify 等），然后发送：

```
请根据「痛点前置型」框架，为以下选题生成完整脚本：

选题：《[你的选题标题]》
核心角度：[你的角度]
目标平台：[B站/抖音/小红书]
时长：[秒数]
我的风格：[你的个人风格描述]
```

AI 就会按模板生成完整脚本。
