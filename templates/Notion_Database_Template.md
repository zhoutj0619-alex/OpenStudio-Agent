## 数据库结构

### 核心字段

| 字段名 | 类型 | 说明 | 示例值 |
|--------|------|------|--------|
| **标题** | Title | 内容标题（必填） | 《我把自己的一人公司开源了》 |
| **类型** | Select | 内容类型 | 选题 / 脚本 / 分发 / 复盘 |
| **阶段** | Select | 当前阶段 | 🟡 待评估 → 🟢 脚本中 → 🔵 拍摄中 → 🟣 剪辑中 → 🟠 待发布 → ✅ 已发布 |
| **平台** | Multi-select | 目标平台 | B站 / 抖音 / 小红书 / YouTube |
| **优先级** | Select | 紧急程度 | 🔴 立即执行 / 🟡 本周 / 🟢 有时间再做 |
| **热度** | Number | 选题热度 1-10 | 8 |
| **脚本公式** | Select | 脚本类型 | 痛点前置 / 反常识 / 故事驱动 |
| **预估时长** | Number | 预计视频时长（秒） | 480 |
| **发布日期** | Date | 计划发布时间 | 2025-07-20 |
| **实际数据** | Rollup | 关联数据表的表现数据 | 播放量 / 互动率 |
| **来源** | Text | 选题来源 | AI 生成 / 热点追踪 / 竞品参考 |

### 视图配置（5 个常用视图）

1. **📅 内容日历** (Calendar View)
   - 按「发布日期」排列
   - 一眼看清本周/本月排期
   - 筛选条件：阶段 ≠ 已发布

2. **🎯 选题池** (Board View)
   - 按「阶段」分组看板
   - 拖拽卡片推进流程
   - 筛选条件：类型 = 选题

3. **✍️ 待拍摄** (Table View)
   - 只显示「脚本中」和「拍摄中」阶段
   - 按优先级排序
   - 隐藏已完成项

4. **📊 本月数据** (Table View)
   - 已发布内容的数据总览
   - 按平台分组
   - 显示播放量/互动率

5. **🔍 Agent 输出** (Table View)
   - 按来源筛选「AI 生成」
   - 查看各 Agent 自动写入的内容

## 与 OpenStudio-Agent 的集成

### 自动写入流程

```
run_daily_digest.py (每日选题)
        │
        ▼
notion_sync.py ────────► Notion 数据库
        │                      │
        │                      ├─ 选题池 (新选题自动入库)
        │                      ├─ 脚本库 (Writer 输出自动归档)
        │                      └─ 分发日历 (Distributor 方案自动排期)
```

### 设置方法

1. 复制此 Notion 模板到你的工作区
2. 在 [notion.so/my-integrations](https://www.notion.so/my-integrations) 创建集成
3. 将集成添加到你的数据库（Share → Invite → 选择你的集成）
4. 复制数据库 ID（从 URL 中提取 `https://notion.so/{workspace}/{database_id}?v=...`）
5. 将数据库 ID 和集成 Token 填入 `.env` 文件
6. 运行 `python workflows/notion_sync.py --agent researcher --input data/xxx.json`

## 最佳实践

- **选题池 ≥ 30 条**：保持选题池里有至少 30 条备选选题，每周集中补充一次
- **周五复盘**：每周五用「本月数据」视图回顾本周表现，标记高互动内容特征
- **一个内容一行**：不要在一个数据库行里放多个平台的版本——用 Relation 关联另一张「分发记录」子表
- **必填字段**：「标题」「类型」「阶段」设为必填，防止空白行
